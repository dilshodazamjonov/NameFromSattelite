# Data Policy

NameFromSatellite only accepts legally supplied, manually provided satellite/aerial image crops for the current MVP.

## Hard Rules

- Do not scrape Google Maps, Google Earth, Yandex Maps, Bing Maps, or any other commercial map/satellite tile service.
- Do not add automatic satellite imagery downloaders for this milestone.
- Do not download commercial map tiles, satellite tiles, labels, overlays, screenshots, or UI assets.
- Do not upload images unless the user has the right to use them.
- Do not use images that include place labels, road labels, pins, icons, controls, watermarks, browser chrome, or other map UI.

## Accepted Inputs

Images should be manually provided by a user/admin and should be:

- clean satellite/aerial crops
- free of map labels and UI overlays
- manually labeled by the uploader with one letter A-Z
- optionally annotated with place, coordinate, or note metadata

## Upload Limits

The current backend accepts:

```text
jpg
jpeg
png
webp
```

Default max upload size:

```text
5 MB
```

The backend also verifies that the uploaded file is actually readable as an image.

## Metadata

Keep source metadata when available:

- manually entered place name
- manually entered coordinates, for example `41 deg 18'57.43"N 69 deg 16'28.81"E`
- source note
- public URL generated by the backend
- relative storage key

The database should store deployable relative storage keys and public URLs, not absolute local filesystem paths.

Reverse geocoding may be used only for user-provided coordinates to fill metadata such as country, region, and city. It must not be used for bulk scraping, grid queries, downloading map data, or commercial tile access.

Supabase Storage may be used to store user-provided uploads. It must not be used as a source for scraping or collecting map imagery.

## Legacy Experiments

Older classifier and candidate scripts are retained only as experiments. They must not be interpreted as permission to scrape, download, or depend on commercial map imagery.
